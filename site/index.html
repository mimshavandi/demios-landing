Demios Desktop

An open-source desktop app for chatting with AI models you choose: one running on your own computer, or a provider you reach with your own API key. No account needed.

Build from source View the code on GitHub

Early and pre-release (version 0.1.0) for macOS, Windows and Linux. There are no installers yet.

Why Demios Desktop

  • Local first

    Chats and settings stay in a database on your computer. Models from the catalogue run on your machine, and nothing leaves it.

  • Your keys stay yours

    Provider API keys are stored in your operating system's keychain, not in a file.

  • Nothing is sent to us

    There is no Demios account, server, analytics or crash reporting.

  • Open source

    Apache-2.0 licence. Read the code, build it yourself, change it.

What it does today

  • Chat with streamed answers, with Markdown and highlighted code blocks. Stop an answer mid-way (⌘. or Ctrl+.) and retry it.
  • Keep conversations on your computer between launches, and delete them with Undo.
  • Run models on your computer with llama.cpp: download one of 12 open models from a built-in catalogue. Each shows whether it fits your machine and its licence. Downloads can be paused, resume after an interruption, and are checked against their SHA-256.
  • Add models from Hugging Face in the app: search GGUF models, and see each size's fit and the model's licence before you download. Downloads are checked against their SHA-256 and resume after an interruption. Gated models use your Hugging Face token, kept in your keychain. Models already in your Hugging Face cache are used in place.
  • Use your own API key for Anthropic, OpenAI or Google Gemini.
  • Add tool servers (MCP) in Settings → Models → Tool servers: a program on your computer or a remote server over HTTPS, with sign-in for servers that need it.
  • See where your data goes in Settings → General, and remove everything with Delete all local data, after a confirmation that lists what will go.
  • A notice on first run, and a line under the message box, say that answers come from the model you chose and can be wrong.
  • Light and dark appearance that follows your system, and keyboard shortcuts for the main actions.
  • Report a problem, or a single answer, through a prefilled form on GitHub. Nothing from your chats is sent.
  • The dn command-line tool: run a model, check whether it fits, and browse and download models from Hugging Face.

Privacy and safety

You decide where each message goes, and tools don't act without your say.

Where your messages go

  • A model on this device: nothing leaves your computer.
  • A provider you added a key for: your messages in that chat go to that provider, under your own account with them.
  • Model downloads: browsing and downloading models contacts Hugging Face. Your chats are never sent there.

Tools ask first

  • Tools a server marks as read-only run without asking.
  • Every other tool asks first. A card in the chat shows the exact arguments, and the tool runs only after you choose Allow once. Tools that only change local data can be allowed for the whole chat. If you don't answer within 10 minutes, the tool doesn't run.
  • A remote server isn't trusted to call its own tools harmless, so none of its tools run without asking.
  • A tool server on your computer needs your OK before it starts. A system dialog shows the exact command, and asks again if the command changes. It runs with your permissions, so add only programs you trust.

More detail is in the privacy policy.

Build from source

You need:

  • Rust 1.89 or newer (stable, with rustfmt and clippy).
  • Node.js 22 and npm.
  • CMake and a C/C++ compiler: llama.cpp, which runs local models, is compiled from source.
  • Platform webview libraries:
    • macOS: Xcode Command Line Tools (xcode-select --install).
    • Linux (Debian/Ubuntu): sudo apt-get install libwebkit2gtk-4.1-dev libayatana-appindicator3-dev librsvg2-dev libxdo-dev libssl-dev
    • Windows: the WebView2 runtime (included with Windows 10 and 11) and the Visual Studio C++ build tools.

Then build and run:

git clone https://github.com/mimshavandi/demios-desktop.git
cd demios-desktop/apps/desktop
npm ci

npm run dev:app      # app window with a built-in test model, no key or download needed
npm run tauri dev    # app window with no model: connect one in Settings
npm run tauri build  # optimised build; the output is in target/release/bundle

The test model in dev:app gives canned answers and is never part of an optimised build. The README and the user guide have the details.
