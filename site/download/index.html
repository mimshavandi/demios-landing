Get Demios Desktop

Preview release · version 0.1.0 · macOS, Windows and Linux

Preview installers are coming shortly. When they're out, each one is listed below with its size and SHA-256. They will be unsigned, so your system will warn you that it can't check who made the app. The steps for each system are below.

For your computer

    Before you install

    • It's an early preview. Expect rough edges, and please report problems.
    • It doesn't update itself yet. To get a newer version, download it from this page and install it over the old one.
    • Signed builds will come later and replace the preview. Moving to one may need one reinstall.

    macOS

    • Apple silicon (M1 and later) .dmg

      Coming shortly

    • Intel Macs .dmg

      Coming shortly

    Not sure which Mac you have? Choose Apple menu → About This Mac. It says "Chip: Apple M…" on Apple silicon, and "Processor: … Intel" on an Intel Mac.

    Opening it

    1. Open the .dmg and drag Demios Desktop to Applications.
    2. Open Demios Desktop. macOS says it can't check the app, and won't open it.
    3. On macOS 15 (Sequoia) and later: go to System Settings → Privacy & Security, scroll down to the message about Demios Desktop, and select Open Anyway. Confirm with your password.
    4. On older macOS: in Applications, Control-click (or right-click) Demios Desktop, choose Open, then select Open again.

    You only need to do this once.

    Opening it

    AppImage: make it executable, then run it.

    chmod +x Demios*.AppImage
./Demios*.AppImage

    .deb: install it with apt. Keep the ./ so apt uses the file.

    sudo apt install ./Demios*.deb

    .rpm: install it with dnf on Fedora, or zypper on openSUSE. Keep the ./ so the file is used.

    sudo dnf install ./Demios*.rpm
    sudo zypper install ./Demios*.rpm

    If apt, dnf or zypper warns that the package isn't signed, that's expected for the preview.

    Check your download

    Each installer will be listed here with its SHA-256, and the release will include a SHA256SUMS.txt file. Compare the SHA-256 of your file with them. If they differ, don't open the file.

    • macOS: shasum -a 256 Demios*.dmg
    • Windows (PowerShell): Get-FileHash .\Demios*.exe
    • Linux, in the folder with your download and SHA256SUMS.txt: sha256sum --check --ignore-missing SHA256SUMS.txt

    Where the files come from

    The installers are built from the public source code and published on GitHub Releases. Downloads come from GitHub, not from demios.io. See the privacy policy for what that means.

    To build the app yourself, follow the build steps in the README.
