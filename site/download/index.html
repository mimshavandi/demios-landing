This is a preview, and the installers are unsigned. Your system will warn you that it can't check who made the app. The steps for each system are below. Check the SHA-256 of your download first.

For your computer

    Before you install

    • The preview installers and the app still use the earlier name, Demios Desktop. The file names and steps below use it too.
    • It's an early preview. Expect rough edges, and please report problems.
    • It doesn't update itself yet. To get a newer version, download it from this page and install it over the old one.
    • Signed builds will come later and replace the preview. Moving to one may need one reinstall.

    Opening it

    1. Open the .dmg and drag Demios Desktop to Applications.
    2. Open Demios Desktop. macOS says it can't check the app, and won't open it.
    3. On macOS 15 (Sequoia) and later: go to System Settings → Privacy & Security, scroll down to the message about Demios Desktop, and select Open Anyway. Confirm with your password.
    4. On older macOS: in Applications, Control-click (or right-click) Demios Desktop, choose Open, then select Open again.

    You only need to do this once.

    Opening it

    AppImage: make it executable, then run it.

    chmod +x Demios-Desktop-0.1.0-preview-linux-x86_64.AppImage
./Demios-Desktop-0.1.0-preview-linux-x86_64.AppImage

    .deb: install it with apt. Keep the ./ so apt uses the file.

    sudo apt install ./Demios-Desktop-0.1.0-preview-linux-amd64.deb

    .rpm: install it with dnf on Fedora, or zypper on openSUSE. Keep the ./ so the file is used.

    sudo dnf install ./Demios-Desktop-0.1.0-preview-linux-x86_64.rpm
    sudo zypper install ./Demios-Desktop-0.1.0-preview-linux-x86_64.rpm

    The preview packages aren't signed, so apt, dnf or zypper may warn about that. Before you continue, check the file's SHA-256.

    Check your download

    Compare the SHA-256 of your file with the one listed above, or with SHA256SUMS.txt from the release. If they differ, don't open the file.

    • macOS: shasum -a 256 Demios-Desktop-0.1.0-preview-macos-arm64.dmg (or the Intel file)
    • Windows (PowerShell): Get-FileHash .\Demios-Desktop-0.1.0-preview-windows-x64-setup.exe
    • Linux, in the folder with your download and SHA256SUMS.txt: sha256sum --check --ignore-missing SHA256SUMS.txt

    Where the files come from

    The installers are built from the public source code and published on GitHub Releases, which also lists every file. Downloads come from GitHub, not from almend.ai. See the privacy policy for what that means.
